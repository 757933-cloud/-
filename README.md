# Наш календарь

Личный PWA-календарь для пары. Тёплые мягкие цвета, иконки сердец на каждом дне, статистика, PIN-код, офлайн-режим.

## Возможности
- Календарь на месяц / год с переключателем
- Три уровня близости: 🤍 была · 🩷 хорошая · ❤️‍🔥 восхитительная
- Настроение 1–5 ⭐ и короткая заметка
- Статистика: за месяц, за год, по уровням, средний интервал, среднее настроение
- PIN-код 4 цифры на входе (хэш SHA-256, без сети)
- Хранение в `localStorage`, экспорт/импорт JSON
- Service Worker — работает офлайн
- Адаптировано под iPhone (safe-area, standalone)

## Запуск локально
```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

## Деплой на GitHub Pages
1. Settings → Pages → Source: Deploy from a branch
2. Branch: ветка с этими файлами, папка `/ (root)`
3. Через минуту приложение откроется по адресу `https://<user>.github.io/<repo>/`

## Структура
- `index.html` — экраны и модалка
- `styles.css` — тёплая палитра, адаптация под iPhone
- `app.js` — вся логика на vanilla JS
- `manifest.json` — PWA-манифест
- `sw.js` — Service Worker (cache-first)
- `icons/` — PWA-иконки 192/512 + maskable
